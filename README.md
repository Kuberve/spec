# Kuberve ABI Specification

Формальные спецификации бинарного интерфейса Kuberve.

**Версия:** 0.1 (draft)
**Статус:** нестабильно, breaking changes возможны без предупреждения.

## Что здесь

- [syscalls/](syscalls/) — номера syscall'ов, ABI, семантика
- [ipc/](ipc/) — формат Message, теги
- [memory/](memory/) — раскладка виртуальной памяти

## Принципы

1. **Один источник истины** — этот репо. `kuberve-abi` crate реализует spec, но spec важнее.
2. **Версионирование** — breaking changes = major bump (v1 → v2), совместимые добавления = minor.
3. **Самодостаточность** — spec не ссылается на docs. Кто-то с копией этого репо должен понять ABI без контекста.

## Совместимость

- `kuberve-abi` crate версии 0.x соответствует spec 0.x.
- Стабильная версия будет 1.0 — тогда обещаем обратную совместимость.
